# PDF Powerhouse

Create a full-stack professional PDF tools website named "UrgentPDFEditor".

Tech Stack:

- Frontend: React + Tailwind CSS

- Backend: Node.js + Express

- Use modern UI like iLovePDF or Smallpdf

- Fully responsive (mobile + desktop)

========================

MAIN FEATURES

========================

Create working tools (ALL must function properly):

1. Image to PDF

2. JPG to PDF

3. PNG to PDF

4. PDF to Word (DOCX)

5. Word to PDF

6. PDF to JPG

7. Merge PDF

8. Split PDF

9. Compress PDF

10. Rotate PDF

11. Add Watermark to PDF

12. Lock PDF (Add Password)

13. Unlock PDF (Remove Password)

========================

FUNCTIONALITY

========================

- Drag & Drop file upload

- Show file preview before conversion

- Show loading/progress indicator

- After conversion, show "Download" button

- Download file automatically using browser download system

- Ensure files download to user's default Downloads folder (mobile/PC)

IMPORTANT:

- Do NOT fake conversion

- All tools must actually process files using libraries

========================

LIBRARIES (IMPORTANT)

========================

Use real working libraries:

- jsPDF (PDF creation)

- pdf-lib (merge, split, edit)

- pdf.js (read PDF)

- mammoth.js (Word conversion)

- docx (create Word files)

- sharp (image processing backend)

========================

UI DESIGN

========================

- Clean modern UI

- White + Blue theme

- Homepage with grid of all tools

- Each tool card clickable

- Navbar with logo "UrgentPDFEditor"

- Footer with links

========================

PAGES

========================

- Homepage (all tools)

- About page

- Contact page

========================

EXTRA FEATURES

========================

- Error handling (invalid file)

- File size limit handling

- Fast performance

- SEO optimized meta tags

========================

SECURITY

========================

- Files should NOT be stored permanently

- Auto delete files after processing

========================

FINAL OUTPUT

========================

- Provide complete working code

- Backend + frontend connected

- Ready to run locally

Make sure everything works properly without errors.
